# Security

Please report vulnerabilities through GitHub's private vulnerability reporting on this repository, not in a public issue.

Timeout Chair reads session logs, which can hold hostile text from web pages, files, or tool output. Reports that show log content steering the investigator, or a proposed fix that weakens a user's security without saying so, are in scope.

The investigator has read-only tools, treats log content as data, and cannot change anything. The main session applies a fix only after the user approves that specific fix. These are model instructions and tool limits, not a guarantee, so always read a proposed change before approving it.
